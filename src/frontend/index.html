2 Liberar o Google Keep

O Google não deixa aplicativos criarem notas em conta pessoal pelo caminho normal. Por isso este passo é manual — mas é uma vez só.

  1. Abra uma janela anônima: Ctrl+Shift+N no Chrome, Edge e Brave; Ctrl+Shift+P no Firefox (no Mac, troque Ctrl por ⌘).
  2. Cole este endereço lá:
    https://accounts.google.com/EmbeddedSetup
  3. Faça login e clique em Eu concordo.
  4. A página vai ficar girando para sempre — isso é normal, pode ignorar.
  5. Aperte F12 → aba Application → Cookies → https://accounts.google.com.
  6. Ache a linha oauth_token, copie o valor (começa com oauth2_4/) e cole abaixo.
⏱️ Esse código vale poucos minutos e só pode ser usado uma vez. Se der erro, repita do passo 1 numa aba anônima nova.

3 Proteger a senha opcional

Sua senha fica salva num arquivo de texto neste computador. Este botão a embaralha usando um recurso do próprio sistema, de um jeito que só funciona nesta máquina — se alguém copiar o arquivo, não serve para nada.
